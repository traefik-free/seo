# Security Policy

## Supported Versions

| Version  | Supported          |
| -------- | ------------------ |
| v0.1.3  | :white_check_mark: |
| v0.1.2   | :white_check_mark: |
| < v0.1.2 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue.
2. Email the maintainers or use [GitHub Security Advisories](https://github.com/traefik-free/seo/security/advisories/new).
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will acknowledge receipt within 48 hours and provide an initial assessment. For critical issues, we aim to release a fix as soon as possible.

Thank you for helping keep this project secure.
